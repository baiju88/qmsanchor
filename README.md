# QMSAnchor — Premier Quality & Accreditation Advisory Platform

A production-grade, responsive web application for **QMSAnchor**, India's premier independent Quality Management System (QMS) consultancy specializing in **NABL** (ISO 15189:2022, ISO/IEC 17025:2017) and **NABH** (Hospital 5th/6th Edition, Entry Level SHCO) accreditation advisory.

---

## 🌟 Key Features

1. **Interactive Accreditation Navigator**:
   - 3-step dynamic explorer covering NABL (Medical, Testing, Calibration, RMP, PT Providers) and NABH (Hospitals, SHCO, AYUSH, Clinics, Dental, Blood Banks, Radiology).
   - Generates custom preparation timelines, mandatory SOP loads, assessor mandays, and quality manager mandates.
   - One-click WhatsApp scope export pre-filling tailored parameters.

2. **NABL & NABH Readiness Calculator**:
   - 5-question operational diagnostic evaluating SOP version control, internal audit/MRM records, PT/EQAS participation, equipment calibration traceability, and statutory NOCs.
   - Computes instant readiness percentage with category diagnosis (High, Moderate, Early Phase).
   - Direct option to dispatch the score and gap list directly to WhatsApp (`+91 8762564150`).

3. **Dynamic Cost & Timeline Estimator**:
   - Calculates official board application and assessment fees, gap rectification duration, and assessor mandays based on facility size and discipline.

4. **Automated Gap Audit Consultation Engine**:
   - Automatically prepares a formatted WhatsApp request directed to **`+91 8762564150`**.
   - Generates an immediate **Automated Acknowledgment Message** for the respondent with a unique Tracking Reference ID (e.g. `QMS-XXXX-XXXX`).
   - Generates ready-to-dispatch email requests to **`qmsanchor@gmail.com`**.
   - Downloadable summary record (`.txt`) for respondent record-keeping.

5. **Direct 24/7 WhatsApp Integration**:
   - Floating WhatsApp widget with pre-configured query quick-prompts and custom message dispatch.

6. **Refined Corporate Design**:
   - Light pink corporate canvas (`#fdf2f4`) with high-contrast slate cards, clinical teal, and accreditation green accents.
   - Expansive edge-to-edge layout filling the entire screen viewport.
   - High-fidelity vector SVG brand logo matching the official emblem (Anchor, 'Q' swoosh, quality checkmark, and tagline *"Your Partner in Quality Excellence"*).

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/qmsanchor-portal.git

# Navigate to project directory
cd qmsanchor-portal

# Install dependencies
npm install
```

### Running Locally

```bash
# Start the Vite development server
npm run dev
```

Open your browser at `http://localhost:3000`.

### Building for Production

```bash
# Compile and build production assets
npm run build
```
